# Wine Yanbert — 와인 시음 저널 웹앱

> 와인을 마신 순간의 첫 반응을 녹음하고, AI가 분석한 재미있는 리뷰와 함께 기록하는 부부의 와인 저널

---

## 1. 프로젝트 개요

### 핵심 컨셉

- 🎙️ 와인을 마시는 순간 **음성 녹음**으로 첫 반응을 기록
- 🤖 녹음 내용을 AI가 분석하여 **재미있는 반응 하이라이트 + 평점 + 테이스팅 노트** 자동 생성
- 📚 와인별 / 지역별 / 날짜별로 시음 히스토리를 탐색

### 사용자

- Yan(남편) & Robert(아내) (2인 전용, 추후 확장 가능)

---

## 2. 핵심 기능

### 2.1 시음 기록 (Recording)

| 기능 | 설명 |
| --- | --- |
| 음성 녹음 | Web Audio API 기반, 와인 마시면서 실시간 녹음 |
| 음성 업로드 | 기존 녹음 파일 업로드 지원 (mp3, m4a, wav 등) |
| 와인 정보 입력 | 와인명, 빈티지, 와이너리, 지역, 나라, 품종, 사진 |
| 와인 라벨 촬영/분석 | 라벨 사진 촬영 → Vision AI로 와인명, 빈티지, 와이너리, 지역, 품종 자동 추출 |

### 2.2 AI 분석 (Analysis)

💡 핵심 전제: 비전문가의 짧은 반응

> 사용자는 와인 전문가가 아님. 녹음 내용은 대부분:
> - 감탄사: "와", "오오", "음..."
> - 짧은 평: "이거 좋다", "시큼한데", "별로야", "지난번보다 낫다"
> - 표정/톤: 웃음, 찡그림, 침묵 → AI는 이런 **최소한의 신호**에서 최대한 의미를 추출해야 함

| 기능 | 설명 |
| --- | --- |
| 트랜스크립션 | 녹음 → 텍스트 변환 (한국어/영어 혼합 지원) |
| 감정/톤 분석 | 음성 톤, 감탄사 강도, 웃음/침묵 감지 → 긍정/부정 판별 |
| 핵심 반응 캐치 | 짧은 한마디라도 캐치 ("와!" → 강한 긍정, "음..." → 미지근) |
| 자동 평점 | 감탄사 강도 + 긍/부정 단어 + 톤 종합 → 5점 척도 |
| 테이스팅 노트 추론 | "시큼하다" → 산미↑, "무겁다" → 바디↑, "향 좋다" → 향↑ 식으로 키워드 매핑 |
| 재미있는 요약 | AI가 짧은 반응을 **과장되고 재미있게** 서술 ("한 모금에 남편 눈이 반달이 됨 🌙") |

AI 프롬프트 전략

```
- 짧은 녹음(10초~1분)도 정상 입력으로 처리
- 감탄사/의성어를 감정 강도로 매핑 (와→4점, 음...→2.5점, 우웩→1점)
- "좋다/괜찮다/별로/싫다" 같은 단순 표현도 평점 + 노트로 확장
- 두 사람의 반응이 다를 경우 대비 포맷으로 표시 ("남편 vs 아내")
- 말이 적을수록 AI가 더 재미있게 포장 (침묵도 해석: "3초간 음미 후 고개를 끄덕였다")
- 이전 시음 기록과 비교 코멘트 자동 생성 ("지난달 마신 XX보다 반응이 뜨거움")

```

### 2.3 취향 프로파일 & 구매 가이드

> 기록이 쌓일수록 부부의 와인 취향을 학습하고, 다음 와인 구매 시 도움을 줌

| 기능 | 설명 |
| --- | --- |
| 취향 프로파일 자동 생성 | 시음 기록 누적 → "산미 높은 프랑스 화이트를 선호" 같은 취향 요약 |
| 선호 패턴 분석 | 높은 평점 와인의 공통점 추출 (지역, 품종, 스타일, 가격대) |
| 비선호 패턴 | 낮은 평점 와인의 공통점 → "이런 건 피하세요" 경고 |
| 남편 vs 아내 취향 비교 | 둘의 취향이 겹치는/다른 영역 시각화 |
| 다음 와인 추천 | 취향 프로파일 기반 "다음에 이런 거 마셔보세요" 제안 |
| 구매 메모 | 와인샵/마트에서 참고할 한줄 가이드 ("바디감 있는 론 쪽 시라 계열 추천") |

취향 학습 로직

```
- 최소 5회 이상 시음 기록이 쌓이면 취향 프로파일 활성화
- 평점 4점 이상 와인의 공통 속성 추출:
  → 선호 품종, 선호 지역, 선호 스타일(바디/산미/타닌 밸런스)
- 평점 2점 이하 와인의 공통 속성 → 비선호 패턴
- 시음 횟수가 늘수록 프로파일 정밀도 ↑ (프로그레스 바 표시)
- 부부 공통 취향 / 개인 취향 분리 표시
- 새 와인 구매 전 "이 와인 우리 취향일까?" 예측 기능 (Phase 2)

```

UI 표현

- 대시보드에 "우리의 취향" 카드 (레이더 차트 + 키워드 태그)
- 통계 페이지에 취향 변화 트렌드 (시간이 지나며 취향이 어떻게 바뀌는지)
- 와인 상세 페이지에 "취향 적합도" 뱃지 (❤️ 딱 맞아 / 🤔 도전적 / ⚠️ 비선호 구간)

🔮 사이비 이론 / 비전문가 포인트 분석

> "라벨에 새 그림 있으면 맛있음" — 이런 비과학적이지만 본인들만의 법칙도 추적하고 검증

| 기능 | 설명 |
| --- | --- |
| 패턴 자동 발견 | 높은 평점 와인들의 비전통적 공통점 자동 추출 (라벨 디자인, 병 모양, 코르크 종류, 가격대 등) |
| 사이비 이론 등록 | 사용자가 직접 가설 등록 ("동물 라벨 = 맛있음", "3만원대가 가성비 최고") |
| 이론 검증 리포트 | 기록이 쌓이면 "당신의 이론 적중률: 78% 🎯" 식으로 검증 |
| 새 와인에 이론 적용 | 구매 전 "이 와인은 당신의 '새 라벨 이론'에 해당함 🐦" 표시 |

```
사이비 이론 학습 로직:
- 라벨 이미지 분석 시 비정형 특징도 태깅 (동물, 식물, 미니멀, 화려 등)
- 높은 평점 와인에서 반복되는 비전통적 패턴을 자동 서제스트
  → "혹시... 동물 라벨 와인 4개 중 3개가 4점 이상인데, 이론으로 등록할까요?"
- 등록된 이론은 이후 시음마다 자동 적중/미적중 기록
- 재미 요소: 이론 적중 시 축하 애니메이션 🎉, 연패 시 "이론 흔들리는 중 😅"
- 이론 랭킹: 적중률 높은 순으로 "우리만의 와인 법칙 TOP 5" 표시

```

UI 표현

- 통계 페이지에 "우리의 사이비 이론" 섹션 (이론별 적중률 바 차트)
- 와인 카드에 해당하는 이론 태그 표시 (🐦 새 라벨 / 🎨 미니멀 / 💰 3만원대)
- 이론 검증 히스토리 타임라인 ("등록 → 3연속 적중 → 첫 실패 → 현재 적중률 75%")

### 2.4 히스토리 뷰 (Views)

| 뷰 | 설명 |
| --- | --- |
| 🍷 와인별 | 같은 와인을 여러 번 마셨을 때 반응 변화 추적 |
| 🌍 지역/나라별 | 프랑스 > 보르도 > 마고 식 계층 탐색 |
| 🏠 와이너리별 | 특정 와이너리 와인 모아보기 |
| 📅 날짜별 타임라인 | 일자별 시음 기록 스크롤 |
| ⭐ 평점순 | Top 와인 랭킹 |

### 2.5 상세 페이지

## 3. 기술 스택 제안

### 프론트엔드

```
Next.js 15 (App Router)
├── shadcn/ui          — 핵심 UI 컴포넌트 (Card, Table, Tabs, Dialog 등)
├── Magic UI           — 애니메이션 (텍스트 리빌, 넘버 티커, 마키)
├── shadcn Charts      — 레이더 차트, 바 차트 (Recharts 기반)
├── Tailwind CSS v4    — 스타일링
└── Framer Motion      — 페이지 전환, 마이크로 인터랙션

```

### 백엔드

```
Next.js API Routes (또는 Server Actions)
├── Supabase           — DB (PostgreSQL) + Auth + Storage (오디오 파일)
├── OpenAI Whisper     — 음성 트랜스크립션
├── Claude Vision / GPT-4o — 와인 라벨 이미지 분석 (와인명, 빈티지, 와이너리 자동 추출)
└── Claude / GPT       — 반응 분석, 테이스팅 노트 생성, 한줄 요약

```

### 인프라

```
Vercel                 — 호스팅 + Edge Functions
Supabase               — 데이터베이스 + 파일 스토리지

```

## 4. 디자인 시스템 선택 근거

### ✅ shadcn/ui + Magic UI + shadcn Charts 조합을 선택한 이유

| 요구사항 | 해결 방법 |
| --- | --- |
| 와인 무드 테마 | CSS 변수 기반 → 버건디/골드/크림 톤 커스텀 용이 |
| 오디오 녹음/재생 | shadcn 기반 커스텀 오디오 컴포넌트 (Web Audio API) |
| 카드 기반 와인 엔트리 | shadcn Card + Avatar + Badge 조합 |
| 다중 뷰 전환 | shadcn Tabs + Command Palette + Data Table |
| 라벨 촬영/분석 | 카메라 캡처 UI + 로딩 스켈레톤 + 자동 필드 채움 애니메이션 |
| 지역 계층 탐색 | shadcn Accordion + Breadcrumb |
| 날짜별 타임라인 | 커스텀 Timeline + shadcn Calendar |
| 재미있는 반응 표시 | Magic UI Text Reveal + Typing Animation + Emoji |
| 평점 시각화 | shadcn Charts 레이더 차트 (산미/타닌/바디/향/여운) |
| 평점 트렌드 | shadcn Charts 라인 차트 (시간에 따른 평점 변화) |
| 바이브코딩 효율 | MCP 지원 → AI IDE에서 컴포넌트 자동 설치 |

### 대안 비교

| 옵션 | 장점 | 단점 | 결론 |
| --- | --- | --- | --- |
| **shadcn/ui + Magic UI** | 최고의 커스텀 자유도, MCP 지원, 바이브코딩 최적 | 조합 필요 | ✅ 선택 |
| Mantine | 올인원 (차트, 타임라인 내장) | 감성적 디자인 커스텀 어려움 | ❌ |
| HeroUI | 기본 디자인 예쁨 | 차트/타임라인 별도 필요 | ❌ |
| MUI | 가장 많은 컴포넌트 | 무겁고, 와인 무드와 안 맞음 | ❌ |

## 5. 테마 디자인 방향

### 컬러 팔레트

```css
/* Wine-inspired palette */
--wine-deep:      #722F37;   /* 딥 버건디 - Primary */
--wine-light:     #A8516E;   /* 라이트 와인 - Secondary */
--gold:           #C5A572;   /* 골드 - Accent */
--cream:          #FDF6EC;   /* 크림 - Background */
--dark:           #1A1A2E;   /* 다크 모드 배경 */
--warm-gray:      #6B5B5B;   /* 텍스트 보조색 */

```

### 타이포그래피

- 제목: Playfair Display (세리프 — 고급스러운 와인 라벨 느낌)
- 본문: Pretendard (한글 가독성)
- 모노: JetBrains Mono (평점/수치)

### 분위기

- 다크모드 기본 (와인 시음은 보통 저녁)
- 카드에 subtle glass-morphism 효과
- 오디오 파형 시각화에 와인 색상 그라데이션
